프로젝트 A `mvp.html` 첫 실행이 오류 7 / 경고 26 이었는데 대부분 오탐이었다.

1. **중첩 템플릿 리터럴** (제일 컸다) — `` `...${ [..].map(t => `...`) }...` `` 의 안쪽
   백틱을 문자열 종료로 오인 → 그 뒤 파싱이 통째로 어긋나 엉뚱한 줄에 "괄호 안 닫힘".
   → 스캐너를 재귀 구조(`_scan` / `_scan_template`)로 다시 씀. `${...}` 안은 문자열이
   아니라 코드이므로 지우지 않고 그대로 훑는다.
2. **정규식 리터럴** — `replace(/'/g, ...)` 의 `'` 를 문자열 시작으로 읽음.
   → 직전 토큰(식별자/키워드/괄호)을 보고 나눗셈과 정규식을 가른다.
3. **`py/arity` 가 스코프를 무시** — `video_planner.py` 에 `_finalize` 가 서로 다른 중첩
   스코프에 둘 있는데 엉뚱한 정의와 대조. `f(*args)` 언패킹도 인자 1개로 셌다.
   → 이름이 파일에 하나뿐 + 메서드 아님 + 언패킹 없음일 때만 검사. 오류 14건이 사라졌다.
4. **미니파이 벤더 파일** — HELM `static/vendor/xterm.js` 에서 `if (a = b)` 50건.
   → `vendor/` 디렉터리·`.min.js` 파일명·줄 길이 휴리스틱으로 제외. `.bak` 등 백업본도.
5. **SVG 를 HTML 규칙으로 판정** — CSS `fill`/`stroke` 를 "알 수 없는 속성",
   인라인 SVG `<circle />` 를 "self-closing 무시됨" 으로.
   → SVG 프레젠테이션 속성 화이트리스트 추가, `<svg>` 안에서는 self-closing 허용.
6. **`.jsonl` 을 통짜 JSON 으로 파싱** — STT 캐시 128건이 전부 "문법 오류".
   → JSON Lines 는 한 줄이 한 문서. 별도 kind 로 분리해 줄 단위 검사.
7. **top-level await 를 문법 오류로** — `new Function(code)` 는 일반 함수 본문이라 거부한다.
   → AsyncFunction 생성자로 파싱. 진짜 문법 오류는 그대로 잡히는지 픽스처로 재확인함.

9. **`from __future__ import annotations` 를 미사용 import 로** — 컴파일러 지시자라 정상. 제외.
